# Маршрут проверки демо — HR Assistant

Как быстро убедиться, что бот обрабатывает резюме: отправить своё
(лучше с обезличенными данными) и проследить путь до скоринга.

## Маршрут проверки

1. **Открыть** [бота в Telegram](https://t.me/PEm05_HR_assistant_bot) →
   **отправить** резюме любым из четырёх способов: текст в свободной
   форме, голосовое сообщение, PDF/DOCX файл или фото.
2. **Дождаться** обработки (в демо-прогон — результат менее чем за
   90 секунд) → **получить** результат matching по открытым вакансиям.
3. **Прочитать** оценку → **увидеть** score 0–100 с разбивкой по
   критериям (роль, навыки, опыт, условия) и вердикт match / no_match
   с обоснованием, а не просто число.
4. **Сравнить**: отправить второе резюме под другой профиль → **увидеть**
   другой score и другую лучшую роль (в E2E-сценарии репо: 100 против
   40 на двух разных вакансиях).

## Что ещё доступно
