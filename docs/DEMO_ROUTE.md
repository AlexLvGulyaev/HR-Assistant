# 🧭 Маршрут проверки демо — HR Assistant

Как за несколько минут убедиться, что бот жив и делает то, что заявлено: отправить резюме и проследить путь до результата matching.

> 🔓 **Доступ:** бот открыт для всех, без регистрации. Отправляйте обезличенные данные — обработка выполняется живым AI-контуром.

## 🧭 Маршрут проверки

1. **Открыть** [бота в Telegram](https://t.me/PEm05_HR_assistant_bot) → **отправить** резюме любым из четырёх способов: текст в свободной форме, голосовое сообщение, PDF/DOCX-файл или фото.
   **Наблюдаемый результат:** бот подтверждает приём и начинает обработку.
2. **Дождаться** обработки → **получить** результат matching по открытым вакансиям.
   **Наблюдаемый результат:** результат менее чем за 90 секунд — текст + аудио + визуальная карточка.
3. **Прочитать** оценку.
   **Наблюдаемый результат:** score 0–100 с разбивкой по критериям (роль, навыки, опыт, условия) и вердикт match / no_match с обоснованием, а не просто число.
4. **Сравнить**: отправить второе резюме под другой профиль.
   **Наблюдаемый результат:** другой score и другая лучшая вакансия (в E2E-сценарии репо — 100 против 40 на двух разных вакансиях).

- Разбор формата оценки и примеры JSON-ответов: [🤝 HR_GUIDE.md](HR_GUIDE.md).
